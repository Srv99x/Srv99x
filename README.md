## Featured Projects

### 🎙️ [VoiceGuard AI](https://github.com/Srv99x/voice-detection-ai)
Deepfake audio detection using Meta's **Wav2Vec2-Large-XLSR-53**, achieving **~91% accuracy**. Built for the HCL GUVI Buildathon — live on Hugging Face Spaces. Includes OWASP-hardened FastAPI backend with JWT auth and CORS policies.

`Python` `FastAPI` `Wav2Vec2` `Hugging Face Spaces` `Gradio`

### 🩺 [MediSense AI](https://github.com/Srv99x/medisense-ai-app)
AI symptom analyzer powered by **Google Gemini 2.5 Flash**. Returns structured condition cards with probability scores and urgency-level triage. Deployed on Vercel + Render. Backend rebuilt from scratch using a teacher-mode learning protocol.

`Python` `FastAPI` `Gemini API` `Gradio` `Render`
